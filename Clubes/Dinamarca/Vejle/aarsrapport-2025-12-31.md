|  | Konklusion |
|  | Vi har revideret årsregnskabet for VB Alliancen A/S for regnskabsåret 1. januar - 31. december 2025, der omfatter resultatopgørelse, balance, egenkapitalopgørelse og noter, herunder anvendt regnskabspraksis. Årsregnskabet udarbejdes efter årsregnskabsloven. |
|  | Det er vores opfattelse, at årsregnskabet giver et retvisende billede af selskabets aktiver, passiver og finansielle stilling pr. 31. december 2025 samt af resultatet af selskabets aktiviteter for regnskabsåret 1. januar - 31. december 2025 i overensstemmelse med årsregnskabsloven. |
|  | Grundlag for konklusion |
| --- | --- |
|  | Vi har udført vores revision i overensstemmelse med internationale standarder om revision og de yderligere krav, der er gældende i Danmark. Vores ansvar ifølge disse standarder og krav er nærmere beskrevet i revisionspåtegningens afsnit "Revisors ansvar for revisionen af årsregnskabet". Det er vores opfattelse, at det opnåede revisionsbevis er tilstrækkeligt og egnet som grundlag for vores konklusion. |
|  | Uafhængighed |
|  | Vi er uafhængige af selskabet i overensstemmelse med International Ethics Standards Board for Accountants' internationale retningslinjer for revisorers etiske adfærd (IESBA Code) og de yderligere etiske krav, der er gældende i Danmark, ligesom vi har opfyldt vores øvrige etiske forpligtelser i henhold til disse krav og IESBA Code. |
|  | Ledelsens ansvar for årsregnskabet |
| --- | --- |
|  | Ledelsen har ansvaret for udarbejdelsen af et årsregnskab, der giver et retvisende billede i overensstemmelse med årsregnskabsloven. Ledelsen har endvidere ansvaret for den interne kontrol, som ledelsen anser for nødvendig for at udarbejde et årsregnskab uden væsentlig fejlinformation, uanset om denne skyldes besvigelser eller fejl. |
|  | Ved udarbejdelsen af årsregnskabet er ledelsen ansvarlig for at vurdere selskabets evne til at fortsætte driften; at oplyse om forhold vedrørende fortsat drift, hvor dette er relevant; samt at udarbejde årsregnskabet på grundlag af regnskabsprincippet om fortsat drift, medmindre ledelsen enten har til hensigt at likvidere selskabet, indstille driften eller ikke har andet realistisk alternativ end at gøre dette. |
|  | Revisors ansvar for revisionen af årsregnskabet |
| --- | --- |
|  | Vores mål er at opnå høj grad af sikkerhed for, om årsregnskabet som helhed er uden væsentlig fejlinformation, uanset om denne skyldes besvigelser eller fejl, og at afgive en revisionspåtegning med en konklusion. Høj grad af sikkerhed er et højt niveau af sikkerhed, men er ikke en garanti for, at en revision, der udføres i overensstemmelse med internationale standarder om revision og de yderligere krav, der er gældende i Danmark, altid vil afdække væsentlig fejlinformation, når sådan findes. Fejlinformationer kan opstå som følge af besvigelser eller fejl og kan betragtes som væsentlige, hvis det med rimelighed kan forventes, at de enkeltvis eller samlet har indflydelse på de økonomiske beslutninger, som regnskabsbrugerne træffer på grundlag af årsregnskabet. |
|  | Som led i en revision, der udføres i overensstemmelse med internationale standarder om revision og de yderligere krav, der er gældende i Danmark, foretager vi faglige vurderinger og opretholder professionel skepsis under revisionen. Herudover: |
|  | uIdentificerer og vurderer vi risikoen for væsentlig fejlinformation i årsregnskabet, uanset om denne skyldes besvigelser eller fejl, udformer og udfører revisionshandlinger som reaktion på disse risici samt opnår revisionsbevis, der er tilstrækkeligt og egnet til at danne grundlag for vores konklusion. Risikoen for ikke at opdage væsentlig fejlinformation forårsaget af besvigelser er højere end ved væsentlig fejlinformation forårsaget af fejl, idet besvigelser kan omfatte sammensværgelser, dokumentfalsk, bevidste udeladelser, vildledning eller tilsidesættelse af intern kontrol. |
|  | uOpnår vi forståelse af den interne kontrol med relevans for revisionen for at kunne udforme revisionshandlinger, der er passende efter omstændighederne, men ikke for at kunne udtrykke en konklusion om effektiviteten af selskabets interne kontrol. |
|  | uTager vi stilling til, om den regnskabspraksis, som er anvendt af ledelsen, er passende, samt om de regnskabsmæssige skøn og tilknyttede oplysninger, som ledelsen har udarbejdet, er rimelige. |

|  | uKonkluderer vi, om ledelsens udarbejdelse af årsregnskabet på grundlag af regnskabsprincippet om fortsat drift er passende, samt om der på grundlag af det opnåede revisionsbevis er væsentlig usikkerhed forbundet med begivenheder eller forhold, der kan skabe betydelig tvivl om selskabets evne til at fortsætte driften. Hvis vi konkluderer, at der er en væsentlig usikkerhed, skal vi i vores revisionspåtegning gøre opmærksom på oplysninger herom i årsregnskabet eller, hvis sådanne oplysninger ikke er tilstrækkelige, modificere vores konklusion. Vores konklusion er baseret på det revisionsbevis, der er opnået frem til datoen for vores revisionspåtegning. Fremtidige begivenheder eller forhold kan dog medføre, at selskabet ikke længere kan fortsætte driften. |

|  | uTager vi stilling til den samlede præsentation, struktur og indhold af årsregnskabet, herunder noteoplysningerne, samt om årsregnskabet afspejler de underliggende transaktioner og begivenheder på en sådan måde, at der gives et retvisende billede heraf. |
|  | uPlanlægger og udfører vi revisionen af årsregnskabet for at opnå tilstrækkeligt og egnet revisionsbevis vedrørende de konsoliderede finansielle oplysninger for virksomhederne eller forretningsenhederne som grundlag for at udforme en konklusion om årsregnskabet. Vi er ansvarlige for at lede, føre tilsyn med og gennemgå det udførte revisionsarbejde. Vi er eneansvarlige for vores revisionskonklusion |

|  | Vejle Boldklub gennemgik i 2025 et markant ejerskifte, som i væsentlig grad kom til at præge hele kalenderåret og klubbens strategiske udviklingsretning. Efter knap ni års ejerskab, hvor Andrew Zolotko besad majoriteten af aktierne, blev klubben i februar overdraget til en gruppe af danske investorer med stærk lokal forankring i Vejle-området. Dette ejerskifte muliggjorde, efter en længere periode præget af begrænset investeringsaktivitet fra det tidligere ejerskab, igangsættelsen af en omfattende organisatorisk og sportslig transformation på tværs af flere niveauer i klubben. Et centralt element i denne omstrukturering var ansættelsen af en direktør for den sportslige sektor, hvilket for første gang i klubbens historie etablerede en samlet og entydig ledelsesansvarlig for hele den sportslige organisation. Denne strategiske tilføjelse, i tæt samspil med det nye ejerskab, bidrog fra begyndelsen til formuleringen af et langsigtet udviklingsperspektiv med fokus på, hvordan Vejle Boldklub mest hensigtsmæssigt kunne allokere sine ressourcer for at opnå og fastholde konkurrenceevne blandt de 12 bedste hold i dansk elitefodbold. |
| --- | --- |
|  | I den indledende fase manifesterede dette sig blandt andet i en målrettet foryngelse af førsteholdstruppen samt etableringen af en mere robust sportslig grundstruktur. Dette blev yderligere understøttet af en udvidelse af den omkringliggende medarbejderstab, ligesom der blev arbejdet systematisk med udviklingen af en bæredygtig talentpipeline baseret på spillere fra klubbens egen talentafdeling. Parallelt blev fokus på rekruttering af udviklingsspillere i en optimal aldersprofil intensiveret gennem etableringen af en ny scoutingfunktion. Samlet set resulterede disse tiltag i en af de mest omfattende trupomlægninger i klubbens nyere historie. De samlede investeringer blev realiseret som følge af et proaktivt og investeringsvilligt lokalt ejerskab, med den overordnede ambition at konsolidere Vejle Boldklubs position som en stabil og permanent aktør i den bedste danske fodboldrække. Sideløbende hermed har klubben arbejdet strategisk og målrettet med fastholdelse af sæsonkortholdere samt en generel optimering af stadionoplevelsen. Dette er blandt andet sket gennem udvikling af billetstrukturer, udvidelse af kampdagsaktiviteter samt forbedring af udbud og købsoplevelser. Indsatsen er yderligere blevet understøttet af dedikerede nyansættelser og en øget ressourceallokering, hvilket allerede har dokumenteret sin værdi som en bæredygtig forretningsmæssig investering. |
|  | Kong Hans Eg Initiativet har i 2025 oplevet en betydelig styrkelse, både i forhold til positionering, lokal forankring og ambitionsniveau. Gennem et helhedsorienteret og systematisk projektarbejde har Vejle Boldklub leveret sit hidtil største bidrag til velgørende og sociale indsatser rettet mod udsatte og sårbare børn, unge og familier siden initiativets etablering i 2020. Dette indsatsområde forventes fremadrettet at indtage en endnu mere central rolle, hvilket også afspejles i klubbens strategiske målsætninger, hvor der er fastlagt ambitiøse og konkrete mål for den samfundsmæssige værdi, klubben ønsker at skabe i og på tværs af Vejle Kommune. På det kommercielle område har Vejle Boldklub gennem det seneste årti oplevet en kontinuerlig vækst i sponsor- og partneraktiviteter. Denne udvikling kulminerede i 2025, hvor klubben realiserede det hidtil højeste aktivitets- og indtægtsniveau inden for sponsor- og partnerskabsområdet. Denne vækstkurve forventes ikke alene fastholdt, men yderligere accelereret over de kommende tre år i overensstemmelse med klubbens strategiske målsætninger. Afslutningsvis har 2025 desuden været kendetegnet ved et omfattende strategiarbejde med henblik på udviklingen af Vejle Boldklubs fremadrettede strategiske fundament. Dette arbejde forventes færdiggjort i marts 2026 og efterfølgende præsenteret i tredje kvartal samme år. Vejle Boldklub afslutter regnskabsåret 2025 med et underskud, hvilket isoleret set ikke kan anses som tilfredsstillende, men som samtidig må betragtes som en direkte og forventelig konsekvens af målrettede og strategisk funderede investeringer i spillertransfers, kontraktuel stabilitet samt den overordnede udvikling og professionalisering af klubbens fodboldforretning. |
