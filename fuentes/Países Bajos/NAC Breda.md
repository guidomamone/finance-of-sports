- **Deporte**: Fútbol
- **Liga / competencia**: Eredivisie (Países Bajos, 1ª división) — ascendido para 2025/26.
- **Entidad legal**: Houdstermaatschappij NAC Breda B.V. (ejercicios viejos) / NAC Breda B.V.
  (ejercicios recientes) — mismo perímetro, denominación distinta según el año.
- **Canal**: sitio propio, un artículo/página nueva por temporada

  una carpeta de archivo vieja (`nac.nl/files/Archief_oude_website/Jaarverslag/`) para años
  anteriores.
